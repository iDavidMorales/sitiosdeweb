# Sitios de Web

Landing estática preparada para Vercel.

## Deploy

Importa `iDavidMorales/sitiosdeweb` en Vercel. No requiere instalación de dependencias, comando de build ni variables de entorno. Vercel servirá `index.html` directamente.

La plantilla visual proviene de `https://routicket.com/negocios/sitiosdeweb-com/?preview=live-1`.
